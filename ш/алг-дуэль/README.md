# Алгебраическая дуэль · 7А vs 7Б

Автономная страница для двух команд (по умолчанию «А» и «Б»). Работает на GitHub Pages или как локальный `index.html`, без PHP, сервера, сборки и внешних библиотек.

## Как провести дуэль

1. Откройте вкладку **Подготовка**. Отметьте отсутствующих — они станут неактивными, а прежние результаты сохранятся. При необходимости измените названия команд и добавьте участников.
2. На первом запуске есть **12 условных участников А (7А)** и **14 условных участников Б (7Б)**. Для реальных ФИ вставьте список «Фамилия Имя», каждый с новой строки, в поле команды и нажмите **Заменить весь состав**. ФИ и оценки не отправляются в GitHub, они хранятся в браузере.
3. Нажмите **Перейти к дуэли** → **Выбрать участников**. Выбор случайный, с попыткой не повторять недавних участников.
4. Нажмите **Выдать задания**. Обе команды получат по одному примеру одной темы из единой пары.
5. Когда кто-то первым решил пример на доске, нажмите **Победа команды А/Б** под соответствующим примером. В модальном окне поставьте **каждому** оценку 2–10. После сохранения автоматически считаются победы и поражения, счёт команд и средние оценки.
6. **Статистика** — общая сводная таблица, личная карточка ученика и история раундов. CSV можно загрузить в Excel. Ошибочно зафиксированный последний раунд можно отменить.

## База заданий

Встроено **338 пар (676 отдельных примеров)**: прежние 128 пар и ещё **210 пар по 21 новому типу** из семи изображений пользователя. На каждый тип приходится 10 аналогичных пар А/Б с разными значениями. Темы включают распределительное свойство умножения, раскрытие скобок со знаками, действия с положительными и отрицательными десятичными дробями, сложение, вычитание и умножение обыкновенных дробей. Каждый пример имеет ответ и пошаговое решение.

Новые задания автоматически добавляются к уже сохранённым данным браузера **один раз** по версии базы `seedRevision=3`. Существующие участники, оценки, статистика и собственные задания сохраняются.

Дополнительные 110 пар хранятся в [`bank-extension.json`](./bank-extension.json), а также встроены в `app.js` и автономный `standalone.html`. При первом запуске обновлённой версии они однократно добавляются к старой локальной базе без удаления участников, оценок и результатов. Удалённые после обновления задания не восстанавливаются повторно.

Во вкладке **Банк задач** можно добавить/изменить/удалить пару, экспортировать весь банк, импортировать дополнительные пары через JSON. Импорт добавляет новые задания, не стирая прежние. Образец: [`tasks-example.json`](./tasks-example.json).

```json
{
  "tasks": [
    {
      "topic": "Раскрытие скобок",
      "level": 1,
      "a": { "question": "2(x + 4)", "steps": ["2x + 8"], "answer": "2x + 8" },
      "b": { "question": "3(y + 5)", "steps": ["3y + 15"], "answer": "3y + 15" }
    }
  ]
}
```

**Принцип:** одна запись массива — один раунд с аналогичными по типу заданиями, но различающимися значениями. `level`: 1, 2 или 3. Внутренние `id` при импорте назначаются автоматически.

## Сохранение

Состояние, список участников, отключения, названия команд, банк задач и история раундов хранятся в `localStorage` **на конкретном устройстве и в конкретном браузере**. Открыв ту же ссылку на другой доске/компьютере, вы не получите старую статистику автоматически. Для переноса нажмите **Резервная копия**, затем на другом устройстве **Восстановить**.

В приватном репозитории `greenn/klass` хранится исходный список класса. В **публичный** `greenn/gp` исходные ФИ несовершеннолетних не копируются; страница поставляется с условными обозначениями. Не публикуйте JSON-резервные копии с ФИ и оценками в открытом GitHub.

## Дополнительные JSON-файлы для импорта

В каталоге [`imports/2026-10-22/`](./imports/2026-10-22/) хранятся **21 отдельных JSON-файлов** — по одному на каждый новый тип (в каждом 10 пар А/Б), а также общий [`all-21-types.json`](./imports/2026-10-22/all-21-types.json) на 210 пар и [`manifest.json`](./imports/2026-10-22/manifest.json) с названиями типов. Формат совместим с кнопкой «Импорт JSON» на странице игры.

При импорте встроенных заданий вручную могут возникнуть повторения. Они уже присутствуют в игре после обновления. Эти файлы предназначены для переноса в другие установки и редактирования банка.

## Файлы

- `index.html` — разметка и интерфейс;
- `style.css` — адаптивная стилизация под интерактивную доску;
- `app.js` — локальное состояние, раунды, оценки, статистика, генерация интерфейса, встроенные задачи;
- `tasks-example.json` — образец расширения банка;
- `bank-extension.json` — 110 пар по примерам четырёх изображений;
- `standalone.html` — полностью автономная версия в одном файле.

Внешние сетевые запросы не используются. **Для запуска без сервера и без Интернета достаточно одного файла [`standalone.html`](./standalone.html): скачайте его и откройте в браузере.** Также можно скачать вместе `index.html`, `style.css`, `app.js` и открыть `index.html` локально.
