# Многослойные трафареты

Интерактивный справочник по исследованию от 5 ноября 2026 года.

Адрес: https://greenn.github.io/gp/ш/труды/трафареты/

8 разделов, 10 собственных сюжетов, 20 шаблонов А4 и 10 SVG-образцов. Инвентарь хранится в браузере, фильтр отображает только подходящие работы. Содержание: 45-минутный урок, полный процесс, граффити, видео, безопасность и сравнение методов.

Исходные данные: [catalog.json](./catalog.json). Собственные рисунки: [assets/](./assets/). Ссылки на внешние работы приведены без копирования чужих изображений. Надёжное размещение ассетов обеспечено GitHub Pages; загрузка на nadube не использовалась.

## Примеры по отдельным URL

- [Общий каталог примеров](./examples/) — 10 школьных рисунков с 3 изображениями, раздельным списком красок и инструментов, чекбоксами наличия и пошаговыми инструкциями.
- [Видео](./videos/) — 8 отдельных страниц разбора YouTube-уроков с демонстрацией, материалами и переходом на оригинал.
- 5 профессиональных кейсов: отдельные страницы с авторскими иллюстративными схемами и ссылками на внешние оригиналы.
