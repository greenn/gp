# Спортивный рейтинг — шаблон на шесть фотографий

Редактор: [открыть](./index.html) · [автономная HTML-версия](./editor-offline.html).

**Размер:** 2400 × 1080 пикселей. **Шесть мест:** золото, серебро, бронза, синий, зелёный, красный.

## Как пользоваться

1. Откройте `index.html` или опубликованную страницу.
2. Перетащите собственную фотографию на нужную рамку (1–6) или выберите место и нажмите «Загрузить фото».
3. Настройте масштаб, положение, цветность, при желании подпишите участника.
4. Нажмите «Скачать PNG» для экспорта изображения 2400 × 1080.
5. Кнопка «Сохранить проект» создаёт JSON со снимками; «Открыть проект» восстанавливает редактирование.

Фотографии **обрабатываются локально в браузере**; веб-страница не загружает их на сервер. Проектный JSON может содержать фотографии, поэтому не публикуйте его случайно.

## Файлы для сборки вручную

- `assets/01_mountains_background.jpg` — фон без спортсменов.
- `assets/02_panel_backplates.png` — подложки шести мест.
- `assets/03_frames_laurels_numbers.png` — верхний прозрачный слой, цифры и лавровые венки.
- `assets/photo-mask-1.svg` — `photo-mask-6.svg` — области фотографий в координатах холста.
- `layout.json` — размеры и точные прямоугольники рамок.
- `editor-offline.html` — самодостаточный редактор с встроенными изображениями, открывается без интернета.

**Порядок наложения:** фон → подложки → фотографии по маскам → верхний слой рамок/номеров → подписи.

Все портреты пользователь вставляет самостоятельно. Изображение с исходными портретами в публичную публикацию не включено.
