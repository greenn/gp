# T2Fb — лаборатория фотопромптов

Интерактивный каталог команд для плагина [T2Fb](https://chatgpt.com/plugins/plugins_6aca023840e881919cb72c5b6c5e7d34), версия справочника 1.0.

**Сайт:** https://greenn.github.io/gp/plg/t2fb/

## Что умеет

- Конструктор `32 @PRESET { parameter=value }` с описанием и примерами **всех 32 параметров** из исследования T2Fb v0.3.0.
- **8 пресетов**: нейтральный, портрет, смартфон, репортаж, предметный, интерьер, ночь, автомобиль.
- **89 коротких команд** формата `22 ...`, включая 10 предоставленных пользователем образцов, с русскими пояснениями и подборкой.
- Настройки для школьных 3D-моделей: сохранение внешности и визуального возраста, без сексуализации.
- Выбор количества ракурсов и типа серии; мгновенная генерация готового текста.
- Копирование полного запроса, команды `32`, коротких команд; TXT и JSON для сохранения набора.
- Поиск, категории, пояснения «что это / когда применять», простая проверка конфликтов.
- Автосохранение **только текста настроек** в localStorage, без передачи на сервер. Изображения на сайт не загружаются.

## Структура

- `index.html` — приложение, без этапа сборки.
- `styles.css` — адаптивное оформление.
- `catalog.js` — открытый справочник 32 параметров и 89 коротких команд.
- `app.js` — интерактивный конструктор, экспорт, проверки и копирование.

## Использование

1. Откройте сайт, выберите пресет (например, `PORTRAIT_EDITORIAL`).
2. Включите необходимые параметры из групп. Чтобы узнать назначение поля, нажмите **«Пояснить»**.
3. При необходимости выберите короткие команды во втором разделе.
4. Выберите справа **«Полный запрос»** и скопируйте.
5. Откройте ChatGPT с плагином T2Fb, приложите 3D-рендер и отправьте команду.

Пример:

```text
32 @PORTRAIT_EDITORIAL {
  focal_mm="85",
  aperture="f/2.2",
  focus_distance="eyes",
  key_light="large window camera-left"
}
```

## Термины и оговорки

- Схема `32` основана на пользовательском исследовании. Это **договорённость инструкций T2Fb**, а не стандарт всех генераторов изображений.
- Префикс `22` для коротких команд взят из пользовательского списка. Дополнительные команды являются **понятными естественно-языковыми шаблонами**, а не системным API.
- Числовые параметры в генеративном изображении описывают желаемую *фотографическую семантику*, но не гарантируют физически точную симуляцию конкретной оптики.
- Фотореализм не гарантирует достоверного восстановления скрытой стороны 3D-модели.
- Публикуйте изображения реальных учащихся с необходимым согласием.

## Источники

Основа: исследование «Мастер-система промптов для преобразования 3D-рендеров в фотореалистичные фотографии», полученное пользователем и добавленное в плагин T2Fb v0.3.0, а также предоставленный список команд `22`.

## Новое в T2F 0.8.0 — единая вкладка `22 next`

Существующая страница `plg/t2fb/` дополнена вкладкой **22 next · Время**. Отдельный параллельный мануал не используется.

- `22 next` / `22 next s` — одна секунда вперёд.
- `22 next 5s` — пять секунд; `22 next -s` — секунда назад.
- `22 next m` / `22 next -m` — минута вперёд / назад.
- `22 next h` / `22 next -h` — час, возможное логичное изменение ситуации и локации.
- `22 next d`, `22 next w`, `22 next mo` — день, неделя, месяц (`m` — именно минута).
- `22 next y` / `22 next -y` — год вперед / назад; визуальный возраст меняется постепенно, по умолчанию то же место.
- `22 next -30s`, `22 next 1.5s`, `22 next 0s` и произвольные положительные интервалы (со знаком `-` для прошлого).

В интерфейсе: отдельная вкладка в существующей навигации, поиск и фильтры по готовым командам, управление направлением, числом и единицей, текстовый модификатор, предпросмотр и **общая правая панель** с кнопками копирования и TXT.

Следующий переход отсчитывается от предыдущего результата (если он доступен). Сначала восстанавливаются известные прошлые кадры, иначе создаётся правдоподобная реконструкция. Фотореализм, возрастосоответствующие ограничения и принцип **одна команда = один кадр** сохраняются. Это не видео и не гарантированный исторический факт. Новый исходник/команда `clean` начинают новую цепочку.

Исходная спецификация доступна в опубликованном плагине T2F: `skills/temporal-frame-transition/SKILL.md`.
