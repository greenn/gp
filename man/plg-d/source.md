# D — интерактивное руководство

Версия плагина: 0.1.1. Дата материала: 7 ноября 2026.
Публичная страница: https://greenn.github.io/gp/man/plg-d/
Плагин: https://chatgpt.com/plugins/plugins_6aef6a93393481919e7300c22efd2897

## Назначение

D — помощник для постановки задач coding agents. По умолчанию он составляет компактный промпт для Codex, а не пишет код. Основа: результат, релевантный контекст, инварианты, автономия и проверка. Детальные планы создаёт по явной команде. Работа с кодом возможна только с помощью фактически подключённых инструментов и разрешений.

## Выбор среды

Codex — результат, ограничения, самостоятельное исследование релевантного кода, проверка; AGENTS.md при необходимости.
Cursor — IDE и agent harness; открытый проект, текущие компоненты и правила .cursor/rules/*.mdc, визуальная сверка при наличии браузера.
Claude Code — буквальный текст ошибок, фактический контекст проекта, CLAUDE.md, Plan Mode при крупных задачах.
Grok / Grok Build — конкретные цели, значимые ограничения и проверка; наличие файловых и IDE-инструментов зависит от выбранного harness.

Cursor и модель нельзя смешивать: D cursor grok означает Cursor как среду и Grok как модель. D cursor claude аналогично.

## Команды

- @D [задача] — короткий промпт для Codex по умолчанию.
- @D prompt [codex|cursor|claude|grok] [задача] — адаптированный промпт.
- @D cursor [задача] — короткая запись для Cursor.
- @D cursor grok [задача] — Cursor с моделью Grok.
- @D cursor claude [задача] — Cursor с моделью Claude.
- @D plan [среда] [задача] — поэтапный план и приёмка.
- @D ui [среда] [задача] — макет интерфейса в copy-ready промпт для разработки.
- @D ui plan [среда] [задача] — подробное проектирование приложения по изображению.
- @D ui build [задача] — реализация UI при доступе к инструментам.
- @D build [задача] — выполнение разработки при доступе к проекту и разрешениях.
- @D fix [среда] [ошибка] — короткая постановка на исправление первопричины.
- @D rules [среда] [проект] — проектные правила AGENTS.md, CLAUDE.md, Cursor Rules.
- @D audit [промпт] — сокращение и улучшение готового промпта.
- @D check [результат] — аудит фактических проверок.
- @D help — помощь.

Порядок платформы может быть после D или после режима: @D cursor ui и @D ui cursor означают один маршрут. Явное указание платформы обычным языком («для Cursor») также учитывается.

## UI из изображения

Внешний вид: композиция, цвета, текст и видимые элементы. Не следует выдумывать невидимые API, сервер или внутренние данные. Требуйте реальные интерактивные компоненты вместо растровой подложки; уточняйте поведение элементов и состояния. Изображение, показанное в ChatGPT, необходимо отдельно передать в IDE/agent, где будет написан код. Абсолютное pixel-perfect не гарантировано без шрифтов, ассетов и проверки.

Пример: @D ui cursor Создай рабочее приложение по приложенному изображению. Сохрани композицию, стиль и подписи. Все видимые элементы сделай функциональными.

## Plan и Build

Plan готовит цель, MVP, экранные состояния, данные, этапы, приёмку, риски и handoff prompt. Не изменяет код.
Build выполняет доступные изменения только в указанном проекте, при наличии средств и полномочий. Нельзя считать упоминание Cursor доступом к запущенному Cursor. Push, деплой, удаление данных, производственные миграции требуют отдельных полномочий.
Fix и check не равны выполнению тестов. Без фактической проверки результат нельзя объявить подтверждённым.

## Правила

Проектные файлы AGENTS.md, CLAUDE.md и .cursor/rules/*.mdc хранят стабильные соглашения, не весь разовый текст задачи. Создавать и менять их только по соответствующей команде и при наличии необходимых полномочий.

## Границы

Данная страница — руководство и локальный конструктор текста, а не подключение к IDE. Команды копируются в ChatGPT с установленным плагином. Скриншоты и файлы не переносятся автоматически между инструментами. Нет гарантии, что в конкретной среде доступны Browser, субагенты, определённая модель или runtime.
