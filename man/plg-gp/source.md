# GP — интерактивная справка

**Версия, использованная для подготовки:** GP 0.2.5, 20.10.2026.
**Назначение:** публичная интерактивная справка команд персонального ChatGPT-плагина GP.
**Путь:** `man/plg-gp/` в GitHub Pages проекта `greenn/gp`.
**Стилистика:** редакционный интерфейс с боковой панелью на светлом фоне; вдохновение пользовательским референсом Shosho. Иллюстрации и оригинальные ассеты другого сайта не копировались.

## Возможности

### VNS — изображения

- `@gp vns`: собрать все доступные сгенерированные GPT изображения текущего чата, их подробные самостоятельные MD-промпты, JSON-описания, индекс и ZIP.
- `@gp vns next`: только новые изображения относительно всех подтверждённых предшествующих сборок VNS и старых collect.
- `@gp vns drive`: сохранить набор на Google Drive в первый свободный каталог `gp/vns/MMDD-N`, сохранить скачиваемый ZIP в чате.
- `@gp vns next drive`: инкрементальный набор + Drive.
- Поддерживается явная подпапка, например `@gp vns drive 1014-2`.

### Drive — материалы задачи

- `@gp drive` → `gp/MMDD` текущей даты пользователя.
- `@gp drive s/2025` → `gp/s/2025`.
- `@gp drive vns cur` → `gp/vns/MMDD`; существующая папка повторно используется.
- `@gp drive vns cur+` → новый первый свободный `gp/vns/MMDD-N`.

### Экспорт истории

- `drive-all` / `drive-all-gpt`: все доступные файлы обеих сторон или только GPT.
- `drive-log` / `drive-log-gpt` / `drive-log-my`: доступные тексты сообщений, вложения, видимые действия/результаты инструментов, предупреждения и ошибки — в скачиваемый ZIP; также попытка загрузить ZIP на Drive.
- `drive-txt` / `drive-txt-all` / `drive-txt-my`: тексты GPT, обеих сторон или только пользователя, без файлов.
- Имена элементов журнала: `N-DDMM-краткая-тема`. ZIP включает `conversation.md`, `messages/`, `events/`, `files/`, `_index.json`, `MANIFEST.json`, `checksums.sha256`, `MISSING.md`, `README.md`.

### IO — публикации

- `@gp io`: публикация текущего результата в `greenn/gp/s/<slug>/`.
- `@gp io ds` или `@gp io ds ?url`: интерактивная HTML-версия исследования в `ds/<slug>/`.
- Ссылка `https://greenn.github.io/gp/<раздел>/<slug>/` выдаётся после подтверждённого коммита; `?url` необязателен.

## Ограничения

GP — набор навыков в ChatGPT, а не сервер постоянной синхронизации. В режиме экспорта нельзя получить скрытые внутренние рассуждения модели, системные секреты, неизвестные сообщения и файлы без доступных байтов. Выгрузки должны отражать реальную доступность данных и честно указывать пропуски. Публикации IO открыты всем.

## Интерактивность справки

- переход по разделам через боковую панель;
- мобильное раскрывающееся меню;
- поиск и фильтры в каталоге команд;
- копирование команд;
- конструктор команд с учётом `cur`/`cur+`;
- раскрывающиеся ответы на часто задаваемые вопросы.

Сайт — статический HTML/CSS/JS без обязательных сторонних библиотек и серверной сборки.

## GP 0.2.4 — Google Docs

- `@gp doc tab @nws` — текущий результат в новую вкладку указанного нативного Google Документа.
- `@gp doc tab @nws "Deep Research"` — задать название.
- `@gp doc tab @nws "Исходный документ" file` — файл PDF/DOCX.
- `@gp doc tab @nws "Все материалы" all` — объединить связанные материалы.
- Упоминание `@nws` — пример; документ должен быть однозначно найден по ссылке или поиску.
- Существующие вкладки нельзя перезаписывать, обычный DOCX нельзя молча преобразовывать.

## Постоянное правило сопровождения GP

Каждое изменение плагина GP обязательно отражать в публичной интерактивной справке `greenn/gp/man/plg-gp/`: разделы, меню, поиск, конструктор, примеры и версия. Обновление плагина без обновления справки считается неполным.

## UPD — обновление существующей страницы по ключу (GP 0.2.5)

- `@gp upd plg-t2f` — найти существующую страницу по части названия каталога и внести описанные пользователем правки.
- `@gp upd man/plg-gp` — явный путь в публичном репозитории.
- `@gp upd plg-t2f добавь раздел «Часто используемые команды»` — ключ и задача в одном запросе.
- `@gp upd https://greenn.github.io/gp/man/plg-t2f/` — точный URL допустим только в границах `greenn/gp`.
- Сначала проверить соответствие ключа доступному существующему каталогу с `index.html`: точный URL/путь, точный сегмент, уникальная часть пути, заголовок или ключевые слова. При нескольких равноценных кандидатах спросить выбор, не писать в GitHub наугад.
- Команда `upd` не означает создание страницы. `io` публикует новый результат, `upd` изменяет существующую страницу, сохраняя URL, поиск, конструкторы, ссылки, адаптивность, исходники.
- В справке добавлены раздел UPD, каталог примеров, поиск/фильтр, пункт меню и конструктор.
