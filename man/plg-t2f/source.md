# T2F 0.8.0 — 22 next: интерактивная справка

Дата: 2026-10-17
Адрес: `https://greenn.github.io/gp/man/plg-t2f/`
Источник правил: действующий навык T2F 0.8.0, `skills/temporal-frame-transition/SKILL.md` в приватном плагине.

## Назначение

Команда `22 next` моделирует один статичный кадр в другом моменте времени. Это не видео и не симуляция камеры. Одна команда — один результат. Не обещается достоверное прошлое или будущее.

## Синтаксис

```text
22 next [±число][s|m|h|d|w|mo|y] [дополнительные условия]
```

- `22 next` = `22 next 1s`
- `22 next s` = `22 next 1s`
- `22 next m` = `22 next 1m`
- `22 next h` = `22 next 1h`
- `22 next y` = `22 next 1y`
- `22 next -s` / `-m` / `-h` / `-d` / `-w` / `-mo` / `-y`: на единицу назад
- `22 next -5s`: на пять секунд назад
- `22 next 0s`: тот же момент, новая генерация может не требоваться.
- `22 next 1.5s`: полторы секунды (разумная дробная величина).
- `22 next 5m keep outfit`: через пять минут, сохранить одежду.

Сокращение `m` — минута. `mo` — месяц. Допускается пробел между числом и единицей: `22 next -5 s`.

## Поведение

| Масштаб | Переход |
|---|---|
| секунды | непрерывное движение рук, ног, взгляда, мимики |
| минуты | продолжение действия, состояние предметов, например яблока |
| часы | развитие ситуации, возможная обоснованная смена места |
| дни/недели/месяцы | быт и обстановка без необоснованных событий |
| годы | изменение визуального возраста, та же локация по умолчанию |

При движении назад сохранять реальные ранее созданные кадры по возможности. Когда прошлое не известно, реконструировать вероятную историю, явно не выдавая результат за факт. Новый исходник создаёт новый `t0`, последующие переходы — от последнего кадра. `clean` сбрасывает цепочку в контексте текущей беседы.

Сохранять возрастосоответствующую подачу, узнаваемость лица, причинность предметов, мягкий натуральный свет и один кадр, если не запрошено иное.
