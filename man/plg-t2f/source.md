# T2F 0.10.1 — NEW, независимые генерации

Обновлено: 20 октября 2026.

NEW — префикс независимой задачи в T2F. Он не удаляет историю чата и не гарантирует технического обнуления модельного контекста. Каждый новый запрос, который должен быть самостоятельным, нужно заново начинать с NEW.

| Команда | Эффект |
| --- | --- |
| `NEW` / `NEW 1` | Новое изображение из текущего текста и новых вложений. Старые настройки, лица, ракурсы, промпты и результаты не наследуются. |
| `NEW 2` | Всё из NEW 1, плюс строгий перечень новых источников: A/FACE, B/OUTFIT, C/SCENE, SOURCE/REF или однозначно описанные новые файлы. При нехватке исходника нельзя подставлять старый. |
| `NEW 3` | Подготовить автономный текст промпта для нового чата с T2F. По умолчанию без генерации здесь и без автоматического открытия нового чата. Вложения необходимо добавить заново. |

## Примеры

```text
NEW 1 77 studio full body
NEW 2 77 FACE=A OUTFIT=B SCENE=C
NEW 2 красный автомобиль на снегу
NEW 3 22 frontal portrait 85mm
```

Все обычные режимы `12`, `22`, `32`, `55`, `77`, `REAL` сохраняются после префикса. `NEW 77` читается как `NEW 1 77`. `clean` отдельно сбрасывает настройки и выполняет стандартную фототрансформацию при новом файле. Без отдельного нового чата абсолютной изоляции нет.
