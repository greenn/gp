## Программирование → Codex → Skills

**Заголовок:** Codex: два способа вызвать Skill.

**Источник:** присланный пользователем скриншот, 22.11.2026. Это сохранение заметки, а не независимая проверка документации.

Сведения из скриншота:

1. Через `/skills`: открыть список Skills, выбрать `install-game-helper`.
2. Через `$`: прямо упомянуть Skill в сообщении, например:

```text
$install-game-helper J:\Games\MyGame
```

В скриншоте сказано, что оба способа описаны в документации OpenAI. Конкретный адрес официальной документации в скриншоте отсутствует; в рамках этой записи ссылка не подтверждена. Путь `J:\Games\MyGame` является примером.

## Команды GP

- `@gp man-ai` — прочитать справочник и ответить по содержимому.
- `@gp upd man-ai` — обновить существующий справочник, распределив сведения по категориям.
- `@gp plg-t2f`, `@gp plg-gp` — прочитать соответствующие опубликованные справки.
- `@gp upd plg-t2f`, `@gp upd plg-gp` — изменить соответствующие существующие справки.

Публичные страницы сами по себе не являются фоновым хранилищем истории беседы; каждое обновление выполняется в момент команды при доступе к GitHub.
