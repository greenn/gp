# Домены `.ru`: цены, регистраторы и бесплатные альтернативы

> Практическая заметка по выбору домена с учётом не только цены регистрации, но и стоимости продления.

## Короткий вывод

Для долгосрочного использования `.ru` важнее смотреть на **цену продления**, а не на акцию первого года.

Оптимальный выбор:

- обычный постоянный проект → `.ru` у дешёвого регистратора;
- тестовый проект → бесплатная зона (`.pp.ua`, `.is-a.dev`);
- серьёзный бренд → лучше свой `.ru`, `.рф` или международная зона.

# Бесплатные домены

## `.pp.ua`

Один из самых практичных бесплатных вариантов.

Пример:

```
myproject.pp.ua
```

Плюсы:

- бесплатная регистрация;
- бесплатное продление;
- полноценная DNS-зона.

Минусы:

- может потребоваться подтверждение телефона;
- нужно проверять доступность регистрации из РФ.

---

## `.eu.org`

Старая бесплатная зона, существующая с 1996 года.

Пример:

```
myproject.eu.org
```

Плюсы:

- бесплатно;
- выглядит лучше старых бесплатных зон.

Минусы:

- ручная проверка заявки;
- ожидание может быть долгим.

---

## `.is-a.dev`

Хороший вариант для разработчиков.

Пример:

```
myproject.is-a.dev
```

Особенности:

- бесплатно;
- управление через GitHub Pull Request;
- можно использовать DNS-записи.

Подходит для:

- демо;
- GitHub Pages;
- тестовых сервисов.

---

## `.js.org`

Бесплатная зона для JavaScript-проектов.

Пример:

```
myproject.js.org
```

Требуется связь с JavaScript-проектом.

# Что случилось с `.tk`, `.ml`, `.ga`, `.cf`, `.gq`

Раньше это были самые известные бесплатные домены Freenom:

```
example.tk
example.ml
example.ga
```

Схема:

```
регистрация бесплатно
↓
бесплатное продление
↓
можно использовать как обычный домен
```

Сейчас эта модель фактически исчезла.

Причины:

- массовое использование в спаме;
- закрытие старой модели Freenom;
- переход многих зон к платной регистрации.

Для новых проектов `.tk` больше не является нормальным выбором.

# Рекомендация для разных задач

| Задача | Выбор |
|---|---|
| Сайт организации | `.ru` |
| Личный проект | `.ru` |
| Пет-проект | `.pp.ua` |
| GitHub-проект | `.is-a.dev` |
| JavaScript библиотека | `.js.org` |
| Эксперименты | `.eu.org` |

## Практический совет

Если проект может стать важным — лучше сразу купить `.ru`.

Стоимость около 200–400 ₽ в год обычно дешевле, чем потом переносить пользователей на новый адрес.
