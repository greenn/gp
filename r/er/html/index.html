01

Соблюдаем вложенность и закрываем теги

Были ошибки с закрывающим тегом </b>: он располагался не на своём месте, а где-то отсутствовал. Теги должны закрываться в порядке, обратном их открытию.

✓ Правильно — вариант 1 
<b><font size="6">Конец</font></b>
✓ Правильно — вариант 2 
<font size="6"><b>Конец</b></font>
✕ Нарушен порядок закрытия 
<b><font size="6">Начало</b></font>
✕ Тег <b> остался незакрытым 
<b><font size="6">Конец</font>
✓ Исправляем незакрытый тег 
<b><font size="6">Конец</font></b>
Запомните:

Если сначала открыли <b>, а внутри него <font>, сначала закрываем </font>, затем </b>.

1б

В конце таблицы нужен </table>

В исходном коде отсутствовал закрывающий тег </table> перед концом документа. Это видно на приложенном фрагменте.

✕ Было 
    </tr>
</html>
✓ Нужно 
    </tr>
  </table>
</body>
</html>

См. визуальный фрагмент приложенного скриншота в разделе «Фрагменты скриншотов» ниже.

02

Разделяем <head> и <body>

По правилам внутри <html> после <head>...</head> должен располагаться <body>. Именно в нём размещается основное содержимое страницы.

✓ Пример структуры HTML 
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет!</h1>
  </body>
</html>
03

Отступы показывают вложенность

Отступы помогают понять, какие элементы находятся внутри других. Они не меняют структуру HTML, но делают код проще для чтения и проверки.

Читаемый вариант 
<table>
  <tr>
    <td align="center">
      <b>Знак</b>
    </td>
  </tr>
</table>
04

Отступы могут быть разной ширины

Можно делать большие или маленькие отступы. Оба варианта синтаксически допустимы. Главное — последовательность и наглядная вложенность.

Более разреженная запись 
<tr>
    <td align="center">
        <font size="6">
            <b>Знак</b>
        </font>
    </td>
</tr>
Компактная запись 
<tr>
  <td align="center"><font size="6">
    <i>Козерог</i></font></td>
</tr>
Важное уточнение по скриншоту: в разреженном варианте на снимке вместо </font> написано <font>. Это отдельная ошибка закрытия тега; ширина отступов здесь ни при чём.
05

Переход на другую страницу через <a>

Ссылка задаётся тегом <a>, а её адрес — атрибутом href. Адрес может вести на соседний HTML-файл или на сайт в интернете.

✓ Локальная страница 
<a href="Овен.html">Овен</a>
✓ Внешний сайт 
<a href="https://ya.ru/">yandex</a>
06

Создаём файл Овен.html рядом с другими

Для ссылки href="Овен.html" нужно создать файл Овен.html в той же папке, что и текущая страница.

Структура папки
сайт/
├── index.html
├── Овен.html
└── Овен.jpg
07

Бегущая строка — <marquee>

Внутри тега <marquee> пишем текст. Его можно обернуть, например, в заголовок <h1>. Атрибуты позволяют задать отскок от краёв и скорость.

Пример с эффектом 
<marquee behavior="alternate" scrollamount="20">
  <h1>♈ ОВЕН — ЗНАК ОГНЯ ♈</h1>
</marquee>
АтрибутЗначение
behavior="alternate"Текст отскакивает от краёв.
scrollamount="20"Скорость движения: чем больше значение, тем быстрее.
08

Добавляем картинку через <img>

В src указывается название файла изображения или адрес изображения в интернете.

Пример из исходного текста 
<img src="Овен.jpg" />
Для HTML5: можно писать и <img src="Овен.jpg">. Полезно дополнительно задать alt — текстовое описание картинки.
09

Центрирование через <center>

Тег <center>...</center> позволяет поместить содержимое по центру страницы. В учебном HTML без CSS такой вариант встречается.

Пример центрирования 
<center>
  <h1>ОВЕН ♈</h1>
  <img src="Овен.jpg" alt="Знак зодиака Овен">
</center>
Современный HTML: элементы <font>, <center> и <marquee> устарели. Здесь они оставлены сознательно, чтобы сохранить логику исходного учебного разбора. В реальных проектах их оформление и анимацию обычно делают с помощью CSS.
