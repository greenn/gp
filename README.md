# GP — GitHub Pages

Публичное хранилище материалов, подготовленных GPT для публикации.

## Правило размещения

- Если пользователь задаёт подкаталог — публикация размещается в нём.
- Если подкаталог не указан — использовать `/s/`.
- Каждую отдельную публикацию хранить в собственной папке; для датированных материалов добавлять дату в формате `-YYYY-MM-DD`.
- Вместе с единой HTML-версией сохранять исходные материалы и связанные файлы, если они нужны для публикации.

## Публикация из ChatGPT через `@gp io`

В проекте работает [публичный каталог](https://greenn.github.io/gp/). Команда плагина GP `@gp io` публикует текущий результат как самостоятельную HTML-страницу в `s/<english-kebab-slug>/`. Команды `@gp io ds` и `@gp io ds ?url` создают интерактивную HTML-версию исследования в `ds/<english-kebab-slug>/`; URL всегда возвращается автоматически, параметр `?url` необязателен.

Для каждой публикации обязательны отдельный `index.html`, исходные материалы при наличии, карточка в главном `index.html` и запись в разделе «Публикации» этого README. Без перезаписи существующих публикаций. Полные требования: [AGENTS.md](./AGENTS.md) и [docs/IO.md](./docs/IO.md). Публикации общедоступны.
