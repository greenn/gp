# INFA / SS — перевод между системами счисления

Автономный учебный калькулятор для школьного урока информатики.

## Возможности
- Основания от 2 до 36; цифры 0–9 и A–Z.
- Конечные дроби на входе (точка или запятая), отрицательные целые и дробные числа.
- Расчёт на JavaScript BigInt, без перевода большого числа в небезопасный тип Number.
- Точное рациональное промежуточное представление N/D.
- Разложение цифр исходного числа по степеням основания.
- Для целой части: цепочка делений с частным и остатком (читать снизу вверх).
- Для дробной части: умножение остатка с выбором новой цифры (читать сверху вниз).
- Период дроби обнаруживается по повторению остатка и обозначается скобками.
- Если за выбранное число разрядов период не найден, запись обрывается многоточием; это обозначено как ограниченная запись без округления.
- Копирование ответа и полного пошагового разбора, печать решения.

## Проверочные примеры
- 156 (10) → 10011100 (2)
- 101101 (2) → 45 (10)
- A3.F (16) → 163.9375 (10)
- 255 (10) → FF (16)
- 0.1 (10) → 0.0(0011) (2)
- -15 (10) → -1111 (2)
- 0 (10) → 0 (36)

Ограничения интерфейса: 120 символов входной записи; максимум 64 дробные цифры на входе. На выходе — до 96 дробных разрядов. Периодическая запись в скобках допустима в ответе, но не во входном поле. Сравнение/округление и работа с двоичными кодами со знаком в дополнительном коде не выполняются.
