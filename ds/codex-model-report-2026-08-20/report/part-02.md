### Скорость

OpenAI не публикует единую абсолютную стандартную величину tokens/sec для всех шести моделей. Поэтому выдумывать ее для таблицы нельзя. Официально для Codex **Fast mode увеличивает скорость поддерживаемых GPT‑5.6, GPT‑5.5 и GPT‑5.4 в 1.5×**, но одновременно в ChatGPT-credit режиме GPT‑5.6/5.5 расходуют credits в 2.5× стандартной ставки, а GPT‑5.4 — в 2×. При API-key эти credit multipliers не применяются.

Есть отдельный новый режим **GPT‑5.6 Sol Ultrafast API**, который не следует путать с reasoning mode **Sol Ultra**. По официальным данным от 13 августа 2026 года Ultrafast достигает **до 750 output tokens/sec** и до 14× скорости Standard; он пока находится в limited preview.

## Методика и пошаговые расчеты

### Почему нет одной «цены токена»

Input, cached input и output стоят по-разному. Следовательно, выражение вроде «цена 1 млн токенов Sol» не имеет единственного значения без указания состава этих токенов. Например, 1 млн output-токенов Sol стоят по API $30, а 1 млн cached-input — $0.50.

Общая формула API:

\[
C_{\$}
=
\frac{I}{1{,}000{,}000}P_I+
\frac{C}{1{,}000{,}000}P_C+
\frac{O}{1{,}000{,}000}P_O
\]

где:

- \(I\) — uncached input tokens;
- \(C\) — cached input tokens;
- \(O\) — output tokens;
- \(P_I,P_C,P_O\) — соответствующие ставки модели.

Codex использует ту же структуру, но со ставками в credits:

\[
C_{credits}
=
\frac{I}{10^6}R_I+
\frac{C}{10^6}R_C+
\frac{O}{10^6}R_O
\]

Именно такую формулу публикует OpenAI.

80{,}000\ cached+
5{,}000\ output
=
105{,}000\ tokens.
\]
