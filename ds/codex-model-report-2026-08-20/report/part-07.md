\rightarrow
Sol\ Max/Ultra
}
\]

Это не шкала «хуже → лучше». Это **эскалация стоимости и reasoning только тогда, когда более дешевый уровень перестает давать требуемый результат**. Такой подход наиболее близок к официальной рекомендации Codex использовать lowest reasoning effort sufficient for the task.

Главная неизвестная остается одна: **ваш фактический недельный allowance**. OpenAI не публикует для вашего аккаунта универсальное число, которое можно достоверно вывести из названия модели. Точное значение и reset следует брать из Usage Dashboard; в CLI `/usage weekly` показывает недельную token activity, а `/status` — текущую сессию и usage. После подстановки этого значения в приведенные формулы можно без дополнительных допущений получить максимальный недельный объем и точный shortfall для каждой модели.
