# Сравнение экономичности моделей Codex при недельном токен-бюджете

## Резюме

На 20 августа 2026 года официальная линейка Codex включает GPT‑5.6 Sol, Terra и Luna, а также предыдущие GPT‑5.5, GPT‑5.4 и GPT‑5.4 Mini. Поэтому обозначения **5.5, 5.4 и 5.4 Mini правильнее считать самостоятельными моделями**, а не версиями Sol/Terra/Luna. OpenAI действительно перечисляет их отдельно. При этом для миграции OpenAI прямо рекомендует **5.4 → 5.6 Terra** и **5.4 Mini → 5.6 Luna**. Для задач, ранее выполнявшихся на 5.5, Terra называется естественной отправной точкой, хотя Sol по уровню семейства примерно соответствует прежнему unsuffixed/frontier-tier.

Главный результат по цене токена:

| Место по тарифу | Модель | Иллюстративная цена за 1M суммарных токенов* | Относительно Luna |
|---:|---|---:|---:|
| 1 | **GPT‑5.6 Luna** | **$0.1105** | 1.0× |
| 2 | **GPT‑5.4 Mini** | **$0.4143** | 3.75× |
| 3 | **GPT‑5.6 Terra** | **$1.1048** | 10× |
| 4 | **GPT‑5.4** | **$1.3810** | 12.5× |
| 5= | **GPT‑5.6 Sol** | **$2.7619** | 25× |
| 5= | **GPT‑5.5** | **$2.7619** | 25× |

\* Для сведения трех разных тарифов в одну цифру я использую одну и ту же смесь токенов для всех моделей: 20k обычного input + 80k cached input + 5k output на каждые 105k токенов. Эта пропорция взята из официального примера OpenAI, но **не является заявленной OpenAI средней нагрузкой Codex**.

Таким образом, если под «cost-efficiency» понимать буквально **сколько обрабатываемых токенов получается на единицу тарифа**, Luna выигрывает с большим отрывом. Terra стоит примерно в 2.5 раза дешевле Sol и GPT‑5.5 по каждому основному типу токена, а Luna — в 25 раз дешевле Sol/5.5. Текущие API-цены составляют соответственно $5/$0.50/$30 за 1M input/cached/output у Sol и $0.20/$0.02/$1.20 у Luna.

Но **Sol Low, Sol Medium, Sol High, Sol Extra High и Sol Max нельзя различать по цене одного токена**: это одна базовая модель с разным reasoning effort. Более высокий reasoning расходует больше токенов и времени, поэтому реальная цена выполненной задачи обычно растет, даже если тариф одного токена остается прежним. OpenAI прямо советует выбирать минимальный reasoning effort, который дает необходимое качество.

**Sol Ultra — особый случай.** Это не отдельная строка тарифа. Ultra использует subagents; в опубликованных тестах стандартная конфигурация координирует четыре агента параллельно. Поэтому цена каждого токена остается ценой Sol, но итоговое число потребленных токенов может существенно увеличиться. OpenAI прямо описывает Ultra как обмен более высокого token usage на более высокое качество и меньший wall-clock time.

Наконец, «недельный лимит Codex» не является одним опубликованным количеством токенов, одинаковым для всех пользователей. OpenAI указывает проверять персональный остаток и reset в Usage Dashboard, `/status` и `/usage weekly`; расход зависит от модели, контекста, reasoning, speed и инструментов. Поэтому без данных вашей учетной записи точный личный остаток посчитать нельзя. Ниже приведены общие формулы и сценарии для **100 тыс., 1 млн и 10 млн токенов в неделю**.

## Что именно сравнивается

### Интерпретация названий

Я нормализую `Sol Ulta` как **Sol Ultra** — именно такое название режима использует OpenAI. Текущие API-документы указывают для GPT‑5.6 Sol/Terra/Luna reasoning levels `none`, `low`, `medium`, `high`, `xhigh`, `max`. В интерфейсах Codex применяются также пользовательские обозначения Light/Low, Medium, High, Extra High, Max и Ultra.

В расчетный набор поэтому включены:

| Семейство | Рассматриваемые варианты | Принцип тарификации |
|---|---|---|
| GPT‑5.6 Sol | Low, Medium, High, Extra High/xhigh, Max, **Ultra** | Один тариф Sol; отличается фактическое потребление |
| GPT‑5.6 Terra | Low, Medium, High, Extra High/xhigh, Max | Один тариф Terra |
| GPT‑5.6 Luna | Low, Medium, High, Extra High/xhigh, Max | Один тариф Luna |
| GPT‑5.5 | самостоятельная модель | собственный тариф |
| GPT‑5.4 | самостоятельная модель | собственный тариф |
| GPT‑5.4 Mini | самостоятельная модель | собственный тариф |

Высший reasoning не получает отдельной ставки «$/token». OpenAI предупреждает, что повышение reasoning effort дает модели больше вычислительного пространства, занимает больше времени и потребляет больше токенов. Поэтому **Sol Medium и Sol High имеют одинаковую цену за идентичное количество input/output tokens, но обычно не одинаковую стоимость выполнения одной задачи**.

### Две возможные трактовки обозначений 5.5/5.4/5.4 Mini

**Основная, наиболее подтвержденная:** это три самостоятельные предыдущие модели. Именно так их показывает актуальная документация Codex. GPT‑5.4 и GPT‑5.4 Mini прекращают работу в Codex с ChatGPT-sign-in **31 августа 2026 года**, то есть через 11 дней после даты этого отчета; API и Codex с собственным API key этим изменением не затрагиваются.

**Альтернативная, как функциональное соответствие при миграции:**

| Старая модель | Возможное соответствие | Основание |
|---|---|---|
| GPT‑5.5 | **Terra** для большинства повседневных прежних 5.5-задач | OpenAI называет Terra естественной отправной точкой для работы, ранее отдававшейся 5.5. |
| GPT‑5.5 | **Sol** по положению в иерархии семейства | OpenAI говорит, что Sol примерно соответствует прежнему unsuffixed tier. |
| GPT‑5.4 | **5.6 Terra** | Это прямое официальное правило миграции Codex. |
| GPT‑5.4 Mini | **5.6 Luna** | Это прямое официальное правило миграции Codex. |

Для 5.5 нет однозначного соответствия reasoning levels новым уровням 5.6. OpenAI это прямо оговаривает.
