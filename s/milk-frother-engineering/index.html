1. Электрическая принципиальная схема Э3

Цепь: GB1(+) → S1 → F1 → +VM → M1(+) → M1(−) → GB1(−). C1, C2 и VD1 соединены параллельно выводам двигателя. Катод VD1 — на +VM, анод — на GND. С1 и С2 подавляют высокочастотные помехи.

* Номинал PPTC F1 подлежит проверке по току запуска, блокировке и температуре. Схема отображает соединения, а не готовую печатную плату.

2. Электрические расчёты

Питание

U₀(нов.) = 2×1,50 = 3,00 В
U₀(исп.) = 2×1,31 = 2,62 В

Принято внутреннее сопротивление одной AA: 0,18 Ом (новая), 0,40 Ом (использованная). Прочие сопротивления = 0,20 Ом.

RΣ(нов.) = 2×0,18 + 0,20 = 0,56 Ом
RΣ(исп.) = 2×0,40 + 0,20 = 1,00 Ом

Падение напряжения и мощность

Для сравнения принят I = 0,35 А (не измерен).

Uм(нов.) = 3 − 0,35×0,56 = 2,804 В
Uм(исп.) = 2,62 − 0,35×1,00 = 2,270 В
Pнов = 2,804×0,35 ≈ 0,981 Вт
Pисп = 2,270×0,35 ≈ 0,795 Вт

Модель двигателя и скорость

Допущения для M1: 3 В; n₀=12 000 об/мин; I₀=0,08 А; ток стопорения от идеального источника Iстоп≈1,2 А; Rм≈3/1,2=2,5 Ом. Оценка по противоЭДС: n ≈ n₀×(Uм−I×Rм)/(3,0−I₀×Rм).

Новые батарейки: ≈ 8 267 об/мин
12000×(2,804−0,35×2,5)/2,8
Использованные: ≈ 5 979 об/мин
12000×(2,270−0,35×2,5)/2,8

Стопорение ротора

Iстоп ≈ 3/(2,5+0,56) ≈ 0,98 А
Pобмотки ≈ 0,98²×2,5 ≈ 2,40 Вт

Реальные значения могут отличаться. Блокировка способна вызвать перегрев; защиту проверить испытанием.
