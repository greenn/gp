# Поездка 24 октября 2026 — распределение по хоррор-квестам

Статический интерфейс для распределения 20 школьников и 2 сопровождающих между квестами «Одержимая» и «Сдаётся квартира».

Две центральные области принимают drag-and-drop. По бокам отображаются списки участников каждой зоны. Снизу — карточки ещё не распределённых участников и сопровождающих. На смартфоне карточку можно выбрать нажатием и затем нажать на нужную область. Распределение сохраняется автоматически в localStorage браузера. Есть копирование списков, печать и сброс.

Фамилии детей **не размещены в открытом коде**. Файл roster.enc.json содержит зашифрованную встроенную базу (PBKDF2-SHA256, 250 000 итераций, AES-256-GCM). Для просмотра один раз требуется код доступа, который хранится у пользователя отдельно от публичного сайта. Никаких загрузок или импортов JSON со стороны пользователя. По выбору пользователя браузер может запомнить код локально — только на доверенных устройствах.

При очистке данных браузера сохранённое распределение исчезает; исходный встроенный список остаётся доступен после повторного ввода кода.
