# GP — локальные страницы класса

В этой папке находится сборщик **двух автономных HTML-страниц**:

- посещаемость, оценки и рейтинг 6 класса;
- поездка, квесты, рассадка в автобусе и баллы.

Исходные данные **не меняются**. Скрипт расшифровывает уже имеющиеся
`initial-data.enc.json` и `roster.enc.json`, объединяет HTML, CSS и JS.
Полученные HTML работают **без интернета, GitHub Pages, Supabase и локального сервера**.

## Запуск на Windows

Откройте терминал в клонированном репозитории `gp`:

```powershell
py -m pip install cryptography
py шк/_local/build.py
```

При **первой сборке** скрипт один раз спросит существующие коды расшифровки.
Он запомнит их в файле `../.gp-local-codes.json` **за пределами репозитория**.
При следующих сборках вводить ничего не потребуется.

Создаются **два готовых файла** в соседней папке `../gp-local/`:

- `attendance.html`
- `trip.html`

Открывайте любой из них двойным щелчком. **На страницах нет окон кодов.**
Списки загружаются сразу. Изменения сохраняются в хранилище браузера,
как и в текущих версиях приложений. Для резервного сохранения
используйте экспорт JSON там, где он предусмотрен.

## Сохранность данных

- В **публичный репозиторий** не записываются ни коды, ни расшифрованные
  ФИО, ни исходные незашифрованные данные.
- Папка `gp-local` и файл `.gp-local-codes.json` специально находятся
  **за пределами git-репозитория**.
- HTML-файлы содержат полные данные и предназначены только для
  личного локального использования. Их нельзя публиковать в GitHub Pages.
- Данные в `localStorage` привязаны к браузеру и месту открытия
  страницы. Для переноса изменений используйте резервные копии.
- При повторной сборке создаётся файл с исходной базой; ранее внесённые
  в браузере изменения не стираются при обычном открытии. Не очищайте
  хранилище браузера без резервной копии.

## Устройство сборки

Вся логика сборки — `build.py`. Без npm, сервера и веб-API.
Для AES-256-GCM используется только библиотека `cryptography`.
Управление оценками, посещаемостью, автобусом и квестами остаётся
на тех же исходных JavaScript-файлах; никаких изменений самих данных нет.

Если существующий исходный HTML или JS изменился так, что сборщик
не может сохранить корректность, он остановится с ошибкой,
не подменяя данные вымышленными значениями.
