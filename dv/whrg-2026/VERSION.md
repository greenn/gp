# WHRG 2026 versioning

Current version: **0.0.30**

Rule used for this microsite:
- Same calendar date: increment the third number for each published change.
- First change on a new calendar date: increment the second number and reset the third number to `1`.

Example: `0.0.30` → next change today `0.0.31`; first change tomorrow → `0.1.1`.
