# WHRG team assets

- `spqr-t2-illustration.webp` — локальная иллюстрация для профиля SPQR, созданная для интерфейса проекта. Это не документальная фотография и не точная копия Booster T2.
- Реальные фотографии/рендеры из первоисточников не выдаются за локальные файлы: их исходные URL, подписи и кредиты сохранены в `../teams.json` и показываются на странице команды.

Такой подход разделяет локальные UI-иллюстрации и документальные изображения из внешних источников.
